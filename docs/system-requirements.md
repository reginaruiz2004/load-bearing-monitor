# System Requirements

## Functional Requirements

- Measure plantar force from both feet.
- Support four sensing regions per foot.
- Sample all eight sensor channels at 20 Hz or greater.
- Convert raw sensor readings into estimated force.
- Transmit measurements through Bluetooth Low Energy.
- Display left and right foot loading in real time.
- Allow clinicians to define a load threshold.
- Activate visual and auditory alerts when the threshold is exceeded.
- Support data export for later analysis.

## Performance Requirements

| Requirement | Target |
|---|---:|
| Number of channels | 8 |
| Minimum sampling rate | 20 Hz |
| BLE packet loss | Below 5% |
| Continuous BLE trial | 30 minutes |
| Calibration R² | At least 0.95 |
| Calibration coefficient of variation | 10% or less |
| Validation MAPE | 15% or less |
| Material cost | Below $999 |

## Physical Requirements

- Wearable during rehabilitation activities.
- Compatible with shoes or rehabilitation boots.
- Adjustable for multiple foot sizes.
- Electronics positioned outside primary plantar loading areas.
- Wiring protected from direct mechanical stress.
- Comfortable enough to minimize alteration of natural gait.
