# Wearable Load-Bearing Monitor for Lower-Limb Rehabilitation

## Overview

The Wearable Load-Bearing Monitor is a bioelectronics and embedded-systems project developed in collaboration with Good Shepherd Rehabilitation. The system is intended to measure and analyze the load applied through the foot during lower-limb rehabilitation.

The device uses force-sensitive sensors, analog signal-conditioning electronics, an external analog-to-digital converter, and an ESP32-S3 microcontroller to collect and wirelessly transmit load measurements. The long-term objective is to provide patients and rehabilitation professionals with objective, real-time information about loading patterns, overloading, and load asymmetry.

> **Project status:** Active development and prototyping.

## Problem

Patients recovering from lower-limb injuries or surgical procedures may be instructed to apply only a specific amount of weight to an affected limb. However, estimating this load without continuous measurement can be difficult.

Existing clinical measurements may provide information during supervised rehabilitation sessions but may not continuously capture how the patient loads the limb during normal activities.

This project investigates a wearable and potentially low-cost method for measuring foot loading and communicating the resulting data in real time.

## Project Objectives

The primary objectives of the project are to:

* Measure force applied at selected locations underneath the foot.
* Convert sensor measurements into repeatable load estimates.
* Detect potential overloading and differences in load distribution.
* Collect data during standing and walking activities.
* Transmit measurements wirelessly using Bluetooth Low Energy.
* Create repeatable sensor-calibration and validation procedures.
* Develop a compact system that can eventually be worn around the ankle or lower leg.

## Hardware Architecture

The prototype is divided into two primary electronic sections.

### Sensor-Conditioning Board

The sensor-conditioning board receives the signals generated by the force-sensitive sensors. It contains the analog circuitry required to convert the sensor resistance changes into measurable voltage signals.

Planned components include:

* FlexiForce force-sensitive sensors
* MCP6004 quad operational amplifier
* Precision resistors
* Decoupling capacitors
* MCP3208 12-bit external ADC
* Keyed sensor connectors
* Headers or connectors for SPI communication

### Control, Communication, and Power Board

The control board processes the digitized sensor signals and transmits the results wirelessly.

Planned components include:

* ESP32-S3 development board
* Bluetooth Low Energy communication
* Battery or regulated power supply
* Power switch
* Status indicator
* Connections to the sensor-conditioning board
* Future battery-monitoring circuitry

## Signal Path

Each force sensor follows this signal path:

```text

→ FlexiForce Resistance Change

→ MCP3208 ADC Conversion
→ ESP32-S3 Processing
→ Bluetooth Transmission
→ Data Visualization
```

## Prototype Development Plan

The project will be developed through several prototype stages.

### Stage 1 — Single-Sensor Breadboard Validation

* Connect one force sensor to a signal-conditioning circuit.
* Read the resulting voltage.
* Apply known loads.
* Record the sensor response.
* Evaluate repeatability, drift, noise, and hysteresis.

### Stage 2 — Multi-Sensor Breadboard Prototype

* Connect multiple sensors.
* Integrate the MCP3208 ADC.
* Read each sensor using the ESP32-S3.
* Develop initial calibration equations.
* Test simultaneous data acquisition.

### Stage 3 — Perfboard Wearable Prototype

* Transfer the validated circuit to perfboard.
* Separate the system into sensor-conditioning and control boards.
* Add secure connectors and soldered wiring.
* Integrate Bluetooth communication.
* Install the electronics inside a wearable enclosure.

### Stage 4 — Custom PCB

* Create the full schematic in KiCad.
* Select production-ready components and footprints.
* Design the sensor-conditioning and control PCB.
* Perform ERC and DRC checks.
* Fabricate and assemble the PCB.
* Compare PCB performance against the perfboard prototype.

### Stage 5 — System Validation

* Perform controlled loading experiments.
* Compare measurements against known reference loads.
* Evaluate accuracy, precision, linearity, hysteresis, drift, and repeatability.
* Test wireless reliability and battery operation.
* Evaluate the mechanical comfort and durability of the wearable enclosure.

## Planned Validation Metrics
